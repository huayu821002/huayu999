A 的关键改动

  • 主价格放大到 54px，货币符号降级到 22px —— 视线第一落点变成价格（你要的「价格也要突出」）。
  • 加 SAVE 41% 角标，比划线价更有促销感。
  • 价格下加 现货 + 仓位 一行绿点（不再是灰灰的 “in stock”）。
  • 仓库从「白底卡片 + 橙色高亮」并入紫卡，改仓库行 + 绿点库存，全页只有一套强调色（玫瑰灰），不再撞色。

字体建议

标题/价格数字：Sora（几何感、数字辨识度高、有商业感）
正文/按钮：Inter（不变，全站统一）
价格数字统一 font-variant-numeric:tabular-nums，换币种不跳版。

方向 B · Split / 留白感（价格卡独立）

价格卡和规格卡拆开：紫卡只放价格 + 阶梯，规格/仓库用白卡 → 层次更清楚、深色面积小、更像成熟 B2B 站。仓库用列表 + 选中态描边（不跟价格抢注意力）。

A vs B 差在哪

  • 深色面积：A 大（整块紫）· B 小（只有价格卡紫）。B 更「干净」，A 更「高级 + 一致」。
  • 价格仍突出：B 用 46px + 白底衬托，价格卡仍是唯一深色块 → 也够醒目。
  • 标题字体换 Plus Jakarta Sans 800（比 Sora 更圆润商务，略带人情味）。
  • 仓库改成列表式：默认仓 badge 单独标出，选中态用莓紫描边 + 淡粉底。
  • 变体按钮在白底上用同款玫瑰灰渐变选中，禁用态灰掉 —— 跟紫卡里的按钮完全一致。

选 B 适合「想让整页看着不像大促页面、更像正经批发目录」的诉求。

C 适合什么

  • 采购员最常用：价格 + 阶梯 + 规格 + 仓位 一屏看完，不用滚。
